# Hotel Aurora — Sistema de Reservas

Aplicación de escritorio (C# · .NET · Windows Forms · JSON · xUnit) para gestionar habitaciones, huéspedes,
reservas, check-in/check-out, cargos y facturación de un hotel mediano.
Proyecto Integrador de Programación II (USPG).

> README inicial (fase 1). Se completa en la fase 9.

## Estructura

- `src/Hotel.Core` — dominio, datos JSON y servicios (sin WinForms).
- `src/Hotel.UI` — interfaz Windows Forms.
- `tests/Hotel.Tests` — pruebas xUnit.
- `docs/` — análisis, requisitos, casos de uso, clases, trazabilidad y UML.
